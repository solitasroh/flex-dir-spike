# 공용 자산 (두 시험 앱이 같은 파일을 쓴다)

- `fonts/` — 엘레나 `planning/design-assets/d2/fetch_fonts.sh` 로 받은 **원본 그대로** (sha256 은 그 스크립트가 검사).
  글꼴 순서: Roboto → Pretendard → 시스템 기본. Roboto 에는 한글이 없으므로 한글은 Pretendard 로 떨어진다.
  - Roboto: SIL OFL 1.1 (`Roboto-OFL.txt`) · Pretendard: SIL OFL 1.1, Reserved Font Name (`Pretendard-LICENSE.txt`) — 수정·서브셋 금지.
- `icons/` — 폴더·파일 아이콘 (스파이크용 단순 SVG). 썸네일은 스파이크 범위 밖.
